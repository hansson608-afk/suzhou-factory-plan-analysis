复盘框架：时间树 × 流程链

时间是一条「树」（大套小），流程是一条「链」（前后有序），问题落在二者的交点上。

时间树（4 层）

月度 → 月度计划 / 产能 / Loss考核 / 产出达成排名 / 呆滞报废
周 → 周计划 / 长周期备料单跟进 / 返工单
日 → 开班规划(T-1) → 备料(T-2h) → 齐套 → 上线 → 交付风险盘点
班次/小时 → 白班/晚班 / 每小时产出通报 / 停线分钟

流程链（6 环节）

需求/订单MO → 周计划 → 开班规划 → 备料 → 齐套 → 生产上线 → 交付 → 复盘(T+1)

关键提前期

  • 需求预测：m+2 / m+3（提前 2~3 个月，拍脑袋来源）
  • 长周期备料单：15~20 天（驱动轮等外协件）
  • 齐套管控：要求提前 7 天齐套
  • 开班规划：T-1 天发布次日排产
  • 备料：T-2 小时备好，晚班备次日料

ABC 分级（帕累托）

评分规则：影响等级 高(5)=停线≥30分或损失≥300台或跨天≥2天；中(3)=停线<30分或损失<300台或跨天1天；低(1)=无。频次 高(3)=一周≥3次；中(2)=1~2次；低(1)=偶发。影响分 = 频次 × 影响。

级问题类频次×影响判断
A缺料/齐套跟不上3×5=15停线+少做的第一大主因
A来料不良反复3×3=9缺料/跳单的重要上游
A备料流程/交接不规范3×5=15部长亲抓的系统性问题
B模具异常（低频高影响）1×5=5单点暴雷，跨天4天
B供应商交付管理2×3=6高频小伤，反复
B设备故障3×1=3高频低单次影响
B物流在途1×5=5偶发但单次损失大
C计划变动（跳单/换型/滚动）3×1=3频繁但多为正常调整
C库存水位/呆滞报废1×3=3偶发，涉资金
结论：A 类 3 个问题是停线和损失的主要来源。来料不良与备料流程是上游根因，缺料是下游结果，治上游两个，缺料会明显收敛。

备料流程不规范备料员不足、值班仓管缺位、三方领料混乱地刷备料流程未对标总装部长亲抓的流程体系问题

问题传导链

① 备料流程不规范 → 备料不及时 → 停线 → 换型损失(2h/次)
② 来料不良 → 返工/挑选 → 缺料 → 停线/跳单
③ 模具异常 → 停产 → 缺料 → 交付风险 → 跨天跟进
④ 供应商交付管理缺失(手写/包装差异) → 账实差异 → 少数 → 停线
⑤ 计划滚动/跳单(m+2/m+3拍脑袋) → 供应商拒备料 → 缺料
核心洞察：5 条链的终点几乎都落在停线/缺料，但根因全在上游的流程、供应商管理、计划预测。只在下游救火治标不治本。

6–8 月趋势背景

  • 6/1 入职，6–8 月只有「刚性执行-计划拉动群」单线，粒度是周计划/开班/排产/模具排查，月度文本量平稳（900~1100 条/月）。
  • 高频词：计划、开班、上线、模具、来料不良、缺料（周级粒度）。
  • 9 月新增 5 个现场群，日粒度的现场问题才集中暴露，备料流程、设备故障、供应商交付管理这些 6–8 月看不到。
